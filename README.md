# StyleMatch – kostenlose Web-App (PWA-Prototyp)

## Enthalten
- Elegantes, minimalistisches Design auf Deutsch
- Kleidung fotografieren oder aus der Galerie auswählen
- Kategorien und digitaler Kleiderschrank
- Einfache Outfit-Vorschläge aus den eigenen gespeicherten Teilen
- Favoriten
- Lokale Speicherung im Browser des Geräts
- PWA-Grunddateien für „Zum Startbildschirm hinzufügen“

## Wichtig
Dies ist ein funktionsfähiger erster Prototyp, keine veröffentlichte Website und keine native APK.
Die App muss über eine HTTPS-Adresse bereitgestellt werden, damit Installation als PWA und Offline-Modus funktionieren. Die Fotos bleiben im lokalen Browserspeicher; Browserdaten löschen kann sie entfernen. Es gibt noch keine automatische KI-Erkennung, Freistellung oder intelligente Farbanalyse.

## Kostenlos veröffentlichen
Das Projekt kann z. B. als statische Website über GitHub Pages veröffentlicht werden:
1. Auf GitHub ein kostenloses Konto erstellen.
2. Ein neues öffentliches Repository anlegen.
3. Die Dateien dieses Ordners hochladen.
4. Unter Settings → Pages die Veröffentlichung aus dem main-Branch aktivieren.
5. Die erzeugte HTTPS-Adresse in Chrome öffnen und im Browser-Menü „Zum Startbildschirm hinzufügen“ wählen.

Alternativ kann ein anderer kostenloser statischer HTTPS-Host genutzt werden.
